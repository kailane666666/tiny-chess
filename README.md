A chess engine in 4 KB of Python: alpha-beta search with iterative deepening, a transposition table, quiescence search, check extensions, killer moves and null-move pruning, playing the make.fun gauntlet through the env. It searches to a fixed node budget, never a clock, so every trial replays move for move.

## Run it

```sh
MAKEFUN_ENV_URL=http://localhost:8080 python3 main.py
```
